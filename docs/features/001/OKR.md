# Milestone 1: Discovery, Prototyping & UX Design

**Delivery alignment:** The first functional product slice (OTP auth, shelves, cards, SRS study, test presets with run API, settings) is described in [docs/architecture/MILESTONE_1.md](../architecture/MILESTONE_1.md). UX work here should track that implementation, not block it.

Before writing complex backend code, we must validate the user journey and ensure the interface naturally manages cognitive load without introducing administrative friction.

- OKR Objective: Validate the core learning loop and user experience design with real learners.
  - Key Result 1: Complete high-fidelity interactive prototypes for the primary active recall and spaced repetition interfaces.
  - Key Result 2: Conduct user testing with 15 early adopters and achieve an 80% positive feedback rate on interface navigation.
